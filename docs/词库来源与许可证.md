# 词库来源与许可证

本项目从以下上游来源构建考试词汇数据。

## 1. ECDICT

- 仓库：https://github.com/skywind3000/ECDICT
- 许可证：MIT
- 许可证状态：`verified`
- 是否可再分发：是
- 本项目用途：
  - 英中基础词条。
  - 考试标签（`cet4`、`cet6`、`ky`、`ielts`、`toefl`）。
  - 音标和基础词性前缀。

## 2. Words-CEFR-Dataset

- 仓库：https://github.com/Maximax67/Words-CEFR-Dataset
- 许可证：MIT
- 许可证状态：`verified`
- 是否可再分发：是
- 本项目用途：
  - 单词级 CEFR 等级映射（`A1` 到 `C2`）。
  - 用于筛选排序的频率信号。

## 3. KyleBing / english-vocabulary

- 仓库：https://github.com/KyleBing/english-vocabulary
- 许可证：实现时未检测到明确的 GitHub 许可证元数据。
- 许可证状态：`needs-review`
- 是否可再分发：否；在取得明确再分发许可或移除派生条目前阻断发布。
- 本项目用途：
  - CET4 / CET6 / 考研词表扩容。
  - 中文释义补强。
  - 用翻译 `type` 字段回填词性。
  - 词组 / 短语支持。
  - 生成 `coverageTier=core` 的核心高频层。

## 4. exam-data / NETEMVocabulary

- 仓库：https://github.com/exam-data/NETEMVocabulary
- 许可证：GitHub API 返回 `NOASSERTION`；再分发前必须核验上游条款。
- 许可证状态：`needs-review`
- 是否可再分发：否；在核验上游条款或移除 NETEM 派生排序字段前阻断发布。
- 本项目用途：
  - 考研词频排序参考。
  - `examFrequencyScore` 与 `examPriorityScore` 计算。
  - 强化 `KAOYAN.core` 核心高频层。

## 5. CC-CEDICT（MDBG 分发版）

- Wiki：https://cc-cedict.org/wiki/start
- 下载：https://www.mdbg.net/chinese/dictionary?page=cc-cedict
- 许可证（MDBG 发布文件）：CC BY-SA 3.0
- 许可证状态：`verified`
- 是否可再分发：是，但必须保留署名并遵守相同方式共享义务。
- 本项目用途：
  - 用中文别名补充匹配覆盖率。

## 构建脚本

- 脚本：`bilibili-vocab-extension/scripts/build-vocab-dataset.js`
- 来源缓存目录：`bilibili-vocab-extension/sources/`
- 生成文件：`bilibili-vocab-extension/data/cet4.json`、`cet6.json`、`kaoyan.json`、`ielts.json`、`toefl.json`、`sources.json`
- 考试导向字段：
  - `partOfSpeech`：由 ECDICT 词性前缀和 KyleBing 翻译类型派生。
  - `coverageTier`
  - `sourceFlags`
  - `altMeanings`
  - `examFrequencyScore`
  - `examPriorityScore`
  - `isPhraseBacked`
  - `phraseCount`

## 合规说明

- 再分发生成数据时必须保留本文档作为来源说明。
- 如果分发的数据包含 CC-CEDICT 派生内容，必须保留署名并遵守相同方式共享义务。
- `data/sources.json` 已包含机器可读的 `licenseStatus`、`redistributable`、`publishBlocking` 和 `reviewAction` 字段。任何 `publishBlocking=true` 的来源在解决前都是发布阻断项。
- `bilibili-vocab-extension/data/` 下的开发快照可能仍包含阻断来源的增强数据，用于本地审计和改进数据集质量。
- `pnpm run pack` 会在压缩前暂存发布安全的数据集：发布构建会排除 `publishBlocking=true` 来源派生的增强字段和补充词条，同时保留 ECDICT / Words-CEFR-Dataset / CC-CEDICT 的已核验来源基线。

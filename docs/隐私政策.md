# 隐私政策

日期：2026-04-27

## 概要

Bilibili Subtitle Vocabulary Extension 设计为在浏览器本地运行。扩展读取视频字幕、页面上下文和扩展设置，只用于提供词汇替换、复习、字幕导航、导出和本地学习统计。

扩展当前没有项目自有的分析服务、账号系统、云同步服务或远程存储后端。

## 处理的数据

扩展可能在浏览器本地处理以下数据：

- 受支持视频页面中的字幕文本。
- 用户从视频上下文收藏单词时的页面 URL、标题、主机名和视频时间点。
- 扩展设置，包括替换比例、词库等级、显示模式、主题、站点规则和悬浮面板布局。
- 学习数据，包括遇到的词、已收藏词、复习队列、反馈、连续学习进度和轻量体验指标。
- 用户主动点击导出时生成的导出数据。

## 本地存储

设置和学习数据存储在 `chrome.storage.local`。

这些数据保留在 Chrome 或 Edge 管理的用户浏览器配置文件中，除非用户主动导出、清理扩展数据、卸载扩展，或使用浏览器自身提供的配置文件同步能力。

## 网络请求

扩展不会把学习数据、已收藏词、设置或指标发送到项目自有服务器。

当前网络行为：

- 在 Bilibili 视频页，内容脚本可能请求 Bilibili 官方播放器和字幕 API，用于加载官方字幕时间轴。
- 在 YouTube 页面，扩展从页面 caption DOM 读取字幕，不会把字幕发送给第三方服务。
- 本地词库文件通过 `chrome.runtime.getURL` 从扩展包内加载。

扩展当前不使用远程翻译、分析、遥测、账号或广告接口。

## 页面内容访问范围

默认自动运行范围仅限：

- `https://www.bilibili.com/*`
- `https://www.youtube.com/*`

`optional_host_permissions: *://*/*` 只用于用户通过显式用户授权 UI 主动授权后的非默认站点网页正文模式，不属于默认数据访问路径。授权成功后，扩展会通过 `scripting` 把已打包的内容脚本注入当前页面。

## 用户控制

用户可以：

- 关闭词汇替换总开关。
- 在 shipped Popup / Options UI 中关闭或恢复当前站点行为。
- 在 Popup 中为非默认站点主动授权或撤销 optional host permission。
- 关闭网页文本模式。
- 从 UI 导出已收藏词和设置。
- 从 Options 清空已收藏生词。
- 通过浏览器扩展数据管理入口清理所有扩展数据，或卸载扩展。

## 数据共享

扩展不会出售、出租或共享用户数据。

导出文件由用户下载后自行控制。如果用户把导出数据导入其他工具，后续处理适用该工具的隐私政策。

## 当前发布状态

默认 manifest 运行范围已经收窄到 Bilibili 和 YouTube。非默认站点网页正文模式需要用户主动授权；用户拒绝授权时不会启用当前站点规则。撤销授权后，当前已注入页面刷新后会完全停止运行。

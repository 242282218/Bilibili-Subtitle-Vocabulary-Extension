# 隐私政策

Bilibili Subtitle Vocabulary（以下简称「本扩展」）高度重视用户隐私。本政策说明扩展如何处理数据。

## 核心承诺

本扩展是**本地优先、零遥测**的浏览器扩展：

- **无账号**：不需要注册、登录或任何身份信息
- **无云同步**：所有数据存储在本地 `chrome.storage.local`
- **无遥测**：不收集、不上报任何使用数据
- **无广告**：不嵌入任何广告或追踪 SDK
- **无远程翻译**：所有翻译基于本地词库，不调用外部 API
- **无自有服务器**：不会把学习数据、已收藏词、设置或指标发送到项目自有服务器

## 数据收集

**本扩展不收集任何用户个人数据。**

## 数据存储

以下数据存储在本地浏览器中，不会离开设备：

| 数据类别 | 存储键 | 内容 | 用途 |
|---|---|---|---|
| 设置配置 | `bili_vocab_settings_v3` | 配置档、全局开关、站点规则 | 控制扩展行为 |
| 生词本 | `bili_vocab_word_stats_v2` | 收藏的单词、命中统计、复习状态 | 学习闭环 |
| 复习队列 | `bili_vocab_review_queue_v1` | 待复习单词队列 | 间隔复习 |
| 学习指标 | `bili_vocab_learning_summary_v1` | 今日/累计学习统计 | 进度展示 |
| 连续学习 | `bili_vocab_learning_streak_v1` | 连续学习天数 | 进度展示 |
| 自动调优 | `bili_vocab_adaptive_tuning_v1` | 自动调优状态与决策 | 策略优化 |
| 体验指标 | `bili_vocab_experience_metrics_v1` | 误替换反馈、调优执行次数 | 策略优化 |
| Onboarding | `bili_vocab_onboarding_v1` | 引导完成状态 | 首次体验 |

## 网络请求

本扩展仅在以下场景发起网络请求：

### Bilibili 字幕

- 请求 Bilibili 官方播放器和字幕 API 获取字幕时间轴
- 请求目标：`api.bilibili.com`、`aisubtitle.hdslb.com`
- 请求内容：视频 BV 号、字幕索引
- 不包含任何用户身份或学习数据

### YouTube 字幕

- 从 YouTube 页面读取 caption DOM，不发起额外网络请求

### 不做的事

- 不向任何第三方服务发送数据
- 不调用远程翻译 API
- 不上报崩溃日志或错误信息

## 站点授权

对于非默认站点（非 Bilibili / YouTube），扩展通过显式用户授权 UI 请求主机权限：

1. 用户在 Popup 中点击「授权当前站点」
2. 浏览器弹出原生授权确认框
3. 用户可随时在浏览器扩展管理页撤销授权

## 数据删除

用户可通过以下方式删除数据：

1. **清空生词本**：Options → 数据与备份 → 清空已收藏生词
2. **恢复默认设置**：Options → 数据与备份 → 恢复默认设置
3. **卸载扩展**：浏览器扩展管理页卸载，所有 `chrome.storage.local` 数据会被清除

## 第三方服务

本扩展不集成任何第三方分析、广告或追踪服务。

## 儿童隐私

本扩展面向一般英语学习者，不专门面向 13 岁以下儿童。不会故意收集儿童个人信息。

## 政策变更

任何隐私政策变更都会通过 Release Notes 和版本号升级明示。继续使用即视为接受更新后的政策。

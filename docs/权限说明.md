# 权限说明

日期：2026-04-27

本文解释 `bilibili-vocab-extension/manifest.json` 中声明的 Chrome / Edge 扩展权限。

## 必需权限

### `storage`

用于把设置和学习数据保存到 `chrome.storage.local`。

示例：

- 当前替换策略。
- 站点规则。
- 已收藏词。
- 复习队列。
- 连续学习进度。
- 用于自动调优的本地体验指标。

### `activeTab`

用于 Popup 与当前活动标签页通信。

示例：

- 读取当前标签页的字幕导航状态。
- 发送上一句、重播本句、下一句等字幕导航命令。
- 在 Popup 中显示当前站点状态。

项目优先使用 `activeTab`，避免默认请求更宽的标签页访问权限。

### `scripting`

用于在用户主动授予 optional host permission 后，把已打包的内容脚本注入当前活动标签页。

它不会绕过站点授权，也不会在未授权站点自动注入。当前用途是让网页正文模式在用户授权的非默认站点具备真实运行路径。

## 默认 Host 权限

### `https://www.bilibili.com/*`

用于在受支持的 Bilibili 页面运行内容脚本，并读取页面内视频字幕上下文。

### `https://api.bilibili.com/*`

用于请求 Bilibili 播放器元数据，从而发现官方字幕轨道。

### `https://aisubtitle.hdslb.com/*`

用于请求 Bilibili 官方字幕时间轴数据。

### `https://www.youtube.com/*`

用于在受支持的 YouTube 页面运行内容脚本，并读取 caption DOM 中的字幕内容。

## 内容脚本范围

默认内容脚本只运行在：

```json
["https://www.bilibili.com/*", "https://www.youtube.com/*"]
```

它不会自动运行在所有 `http://*/*` 或 `https://*/*` 页面。

## Web Accessible Resources

打包词库数据和 React overlay bundle 仅暴露给默认支持页面：

```json
["https://www.bilibili.com/*", "https://www.youtube.com/*"]
```

这保证扩展资源暴露范围与默认运行范围一致。

## Optional Host 权限

manifest 当前声明：

```json
["*://*/*"]
```

这是为“用户授权后的网页正文模式”保留的能力，不属于默认自动注入路径。

当前 UI 已提供：

- 当前站点授权状态。
- 用户主动点击的授权按钮。
- 拒绝授权后不启用当前站点的处理逻辑。
- 关闭站点规则或撤销授权的入口。
- 明确说明网页正文模式只读取可见页面文本，并仅用于本地词汇替换。

用户也可以在浏览器扩展详情页撤销 optional site access。通过 Popup 撤销授权后，已注入的当前页面需要刷新后才会完全停止运行。

## 未请求的权限

扩展当前不请求：

- `tabs`
- `history`
- `cookies`
- `webRequest`
- Native messaging
- 远程代码执行相关权限

## 当前发布门槛

默认 Bilibili / YouTube 主路径已经符合最小权限原则。非默认站点网页正文模式已经具备 optional permission 授权、拒绝保护和撤销入口；zip smoke 与 release check 已有自动化门禁。投入发布候选前仍需要完成真实站点 E2E 和词库来源合规门禁。
